## Descripción del proyecto
En el desarrollo de proyectos de software y en la vida académica en general, la organización de tareas es determinante para cumplir los objetivos planteados. Los equipos que no llevan un control claro de sus pendientes suelen depender de medios poco estructurados —notas físicas, hojas de cálculo o chats de WhatsApp— que no permiten dar seguimiento real al estado de las actividades.
Este proyecto propone construir y evaluar una aplicación web de gestión de tareas (To Do List) desarrollada en Java, midiendo de forma concreta el tiempo que toma realizar las operaciones básicas (crear, editar, completar y eliminar tareas) y la percepción de facilidad de uso de quienes la prueban, para determinar si una herramienta propia y simple puede ofrecer una gestión más eficiente que los métodos informales.

## Pregunta de investigación
## Principal
 ¿En qué medida una aplicación web de gestión de tareas desarrollada con Java mejora la eficiencia en el registro, organización y seguimiento de las actividades de los usuarios?
 
## Secundarias
¿Cuánto tiempo requiere un usuario para registrar, modificar, completar y eliminar una tarea utilizando la aplicación?
¿Cómo influye la centralización de las tareas en el seguimiento del estado de las actividades pendientes y completadas?
¿Qué nivel de facilidad de uso perciben los usuarios al utilizar la aplicación para organizar y dar seguimiento a sus tareas?>

## Objetivos
Objetivo general
Evaluar la eficiencia de una aplicación web de gestión de tareas desarrollada en Java en el registro, la organización y el seguimiento de las actividades de los usuarios.
Objetivos específicos
Construir un prototipo funcional de la aplicación con operaciones básicas de creación, edición, finalización y eliminación de tareas.
Medir el tiempo que tarda un usuario en completar cada una de esas operaciones dentro de la aplicación.
Evaluar la percepción de facilidad de uso de los usuarios de prueba mediante una encuesta estructurada.
Analizar los datos recolectados para determinar el nivel de eficiencia de la herramienta.
Proponer mejoras a la aplicación con base en los resultados obtenidos.
